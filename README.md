### 🚀 Sobre mí
Estudiante de **Ingeniería en Informática**. Mi religión es la reproducibilidad: si un proyecto requiere un README de 800 líneas y rezar tres padres nuestros para compilar, algo salió muy mal.

* **Enfoque:** Construir cosas, romperlas y luego automatizar cómo arreglarlas.
* **Filosofía:** "Infraestructura pequeña, pero útil". Prefiero un `Makefile` sólido que mil pasos manuales.
* **Intereses:** Backend, arquitectura de sistemas y el ecosistema Docker.

### 📦 El "Frank Standard" (Filosofía de Proyectos)

Mis proyectos públicos (y los crímenes privados) intentan seguir el flujo sagrado:

```bash
git clone repo
cd proyecto
make up # Docker levanta todo, las migraciones corren solas, el café se sirve caliente.

```

**Si no se levanta así, probablemente el desarrollador original (yo) tuvo un mal día.**
